# UNITES Website

A responsive static website for UNITES, focused on:
- Plasterboard ceilings
- POP ceilings
- Acoustic ceilings
- Interior and exterior painting
- Wall preparation

## Preview locally
Open `index.html` in a web browser. Internet is needed for the Google Fonts and sample Unsplash photos.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `unites-website`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the published website URL in the Pages section.
